# JASMINE PARK 포트폴리오 작업 인계

업데이트: 2026년 10월 16일

JASMINE PARK의 작업과 사진을 보여주는 개인 포트폴리오입니다. 이 문서는 사용자가 선택한 디자인 방향과 현재 구현 상태를 정리합니다. 작업을 시작할 때 최신 소스와 함께 읽고, 이후 사용자의 요청이 바뀌면 해당 결정도 갱신합니다.

## 주소와 저장 위치

- 사용자가 확인 중인 Vercel 주소: https://optinomai.vercel.app/
- GitHub Pages 주소: https://cornsrfab.github.io/optinomai/
- 소스 저장소: https://github.com/cornsrfab/optinomai
- 소스 브랜치: `main`

현재 사이트 실행에 필요한 파일은 저장소 루트의 `index.html`, `style.css`, `app.js`, `void.js`입니다. 별도 프레임워크, 패키지 설치, 빌드, 서버 API나 데이터베이스를 사용하지 않습니다. Canvas 2D에 원근 투영을 적용해 3D처럼 그리며 WebGL이나 Three.js 기반은 아닙니다. `void.js`를 `app.js`보다 먼저 로드해야 합니다.

GitHub Pages는 `main`의 `/(root)`를 소스로 설정했고 배포 성공을 확인했습니다. Vercel 연결 설정은 계정의 프로젝트 설정에서 확인해야 하며 저장소에 Vercel 프로젝트 식별자나 설정 파일은 없습니다. 정적 사이트를 연결할 때는 Framework Preset을 Other로, 출력 위치를 루트로 지정하고 빌드 명령은 비웁니다.

## 확정된 시각 방향

흰 배경에 회색 이미지 조각으로 만든 입체적인 눈이 주인공입니다. 의료 도해처럼 정교한 인상을 원하지만 큰 제목과 긴 설명은 원하지 않습니다.

왼쪽에는 각진 검은 J 모노그램, 연도별 작업 목록, 사진 카테고리, 연락처를 세로로 배치합니다. 한때 로고를 왼쪽 중앙에 단독 배치했으나, 최종 요청은 참고 사이트처럼 로고 아래에 작업을 연도별로 길게 나열하는 방식입니다.

- 이름: JASMINE PARK. OCULUS는 초기 임시 브랜드였으며 현재 표시 이름은 JASMINE PARK입니다.
- 로고: 그리스 이오타의 기둥과 J의 꺾임을 결합한 브루탈리스트 모노그램. 그리스 알파벳에 J가 있다는 뜻은 아닙니다. `index.html`의 인라인 SVG입니다.
- 작업 목록: 2026부터 2020까지 내림차순. 연도는 검정, 작업명은 연회색이며 호버와 포커스 시 진해집니다.
- 글꼴: 참고 사이트에서 확인한 `sans-serif`, 10px, 줄간격 17px. 별도 웹폰트 파일은 없습니다.
- 메뉴 순서: 연도별 작업 → personal archive → astrophotography → contact info.
- 눈의 표시자: SCLERA, IRIS, PUPIL / VOID 라벨, 가는 연결선과 작은 원, 십자, 회전 각도를 유지합니다. 눈만 남긴 화면이 단조롭다는 피드백으로 복원했습니다.
- 큰 히어로 제목, 소개 문구, 슬로건을 다시 넣지 않는 방향입니다.

디자인 참고:
- https://daviestoews.com/ — 작은 글씨와 연도별 세로 작업 목록.
- https://www.travisscott.com/ — 오브젝트를 중심으로 한 인터랙션의 참고. 현재 구현은 사용자가 요청한 눈의 스크롤 회전입니다.
- Stellarium의 천구 좌표 이미지 — 동공 속 공간의 시각적 참고. 실제 천문 데이터나 Stellarium 라이브러리를 사용하지 않습니다.
- https://leesopcho.com/text-by-me — personal archive와 astrophotography 추가 요청 당시 공유된 브라우저 맥락이며, 구체적인 복제 지시는 없었습니다.

## 확정된 인터랙션

초기에 마우스 커서를 따라보는 버전을 만들었으나 사용자가 이전 방식이 더 좋다고 선택했습니다. 현재는 커서 추적을 사용하지 않습니다.

1. 기본 상태에서 천천히 좌우로 자동 회전합니다. 움직임 줄이기 설정에서는 자동 회전을 기본으로 끕니다.
2. 눈을 드래그하면 직접 회전합니다.
3. 메인 화면에서 휠이나 트랙패드를 스크롤하면 수평으로 360도 연속 회전하고, 반대 방향 스크롤은 역회전합니다. 현재 감도는 정규화된 스크롤 1200 CSS 픽셀당 한 바퀴이며, 입력 한 번의 최대 반영량은 600픽셀입니다.
4. 드래그와 스크롤 이후 약 1.4초 동안 자동 움직임을 쉬었다가 켜져 있던 자동 회전을 재개합니다.
5. 회색 이미지 조각을 클릭하면 정사각형 이미지 뷰어가 열립니다. 작업 목록과 이미지 목록에서도 같은 뷰어를 엽니다.
6. 중앙 동공을 클릭하거나 공간 버튼을 누르면 어두운 구형 3D 공간으로 진입합니다. 내부에서 드래그, 방향키, 휠, 확대·축소 버튼을 사용할 수 있습니다. ESC 또는 복귀 버튼으로 눈 화면으로 돌아옵니다.
7. 동공이 뒷면에 있을 때 내부 공간을 앞면에 그리거나 클릭 대상으로 남기지 않도록 처리했습니다.
8. 오른쪽 아래에는 자동 회전, 정면 초기화, 공간 열기, 이미지 목록 아이콘이 작게 있습니다.
9. personal archive와 astrophotography는 각각 6개의 임시 이미지가 있는 별도 목록을 엽니다. 현재는 두 카테고리가 기존 12개 더미의 앞 6개와 뒤 6개를 나눠 사용합니다.

## 작업과 이미지의 현재 상태

실제 프로젝트 이름, 연도, 사진은 아직 받지 않았습니다. 왼쪽의 다음 작업명과 연도 조합은 레이아웃용 임시 배치이며 실제 이력으로 취급하면 안 됩니다.

| 임시 연도 | 임시 작업명 |
| --- | --- |
| 2026 | soft focus, silver lining |
| 2025 | quiet surface, after light |
| 2024 | inner space, fading form |
| 2023 | between shadows, still motion |
| 2022 | pale horizon, light study |
| 2021 | slow exposure |
| 2020 | open field |

눈 표면의 조각은 `patches`와 `draw()`에서 절차적으로 그리는 곡면 그라데이션입니다. 뷰어와 목록의 더미는 `names`, `gradients` 배열로 구성합니다. 눈의 조각에 주어진 `index`와 왼쪽 메뉴의 `data-image`가 0부터 11까지의 항목으로 연결됩니다.

현재 실제 사진 로딩, 업로드 관리자, CMS, 이미지 자동 검색은 구현되어 있지 않습니다. 눈 표면의 그라데이션과 이미지 뷰어의 그라데이션은 별도의 렌더링입니다. `gradients`만 바꿔서는 눈 표면이 사진으로 바뀌지 않습니다.

## 사진을 추가할 때

아래 폴더는 향후 권장 구조이며 아직 저장소에 만들어진 폴더가 아닙니다.

- `images/projects/`: 프로젝트 이미지
- `images/personal/`: 개인 아카이브 사진
- `images/astro/`: 천체사진

사진을 받을 때 파일과 함께 작업명, 실제 연도, 카테고리, 표시 순서를 확인합니다. 파일을 저장소에 넣은 뒤 이미지 경로를 항목 데이터에 연결하고, 뷰어와 목록이 실제 이미지를 사용하도록 수정해야 합니다. 눈 표면에도 사진을 보이게 하려면 이미지 로드와 곡면 조각별 텍스처 투영 또는 클리핑 렌더링을 별도로 구현해야 합니다.

항목이 늘어날 때는 현재의 고정 길이 12, 모듈로 연산, 인덱스 매핑을 함께 수정합니다. 장기적으로는 항목별 id, title, year, category, image 경로를 담는 공통 데이터로 통합하면 수정 지점을 줄일 수 있습니다. 이는 후속 개선안이며 현재 구현 상태가 아닙니다.

저장소가 공개이므로 게시할 웹용 이미지와 사용자에게 게시 승인을 받은 콘텐츠만 올립니다. 개인 원본이나 공개를 의도하지 않은 메타데이터는 포함하지 않습니다. GitHub Pages에서도 동작하도록 상대 경로를 사용합니다.

## 수정과 확인

화면 구조와 목록은 `index.html`, 스타일은 `style.css`, 눈과 뷰어·목록은 `app.js`, 내부 공간은 `void.js`에서 수정합니다. `style.css`에는 초기 스타일과 후속 덮어쓰기 규칙이 함께 있으므로 뒤쪽 규칙과 모바일 미디어 쿼리도 확인합니다.

JavaScript를 수정한 경우 아래 구문 검사를 실행합니다.

```sh
node --check app.js
node --check void.js
```

변경과 관련된 브라우저 동작을 확인합니다. 회전 변경이라면 정면·옆면·뒷면, 순방향·역방향, 자동 회전 중지·초기화를 확인합니다. 이미지 변경이라면 타일·왼쪽 목록·카테고리에서 열기와 이전·다음·닫기를 확인합니다. 공통 변경은 모바일 목록과 연락처, 동공 진입·복귀도 확인합니다.

작업 전 최신 `main`을 읽고 다른 수정과 충돌하지 않도록 반영합니다. 게시 후에는 해당 커밋의 배포 성공과 실제 사이트 반영을 확인합니다. GitHub Pages 배포와 Vercel 배포는 서로 별개이므로 한쪽 성공을 다른 쪽 성공으로 보고하지 않습니다.

## 이어서 할 작업

사용자가 새로 요청하는 작업을 우선합니다. 현재 남은 콘텐츠 작업은 실제 작업명·연도·사진 수집과 더미 교체입니다. 이미지 업로드만으로 자동 반영되는 시스템은 아직 없으므로, 콘텐츠 연결 또는 관리 방식 구현이 필요합니다.

이 기록은 대화 전체의 복사본이 아니라 작업에 필요한 결정과 구현 상태를 담은 인계 문서입니다. 새 채팅은 이 문서와 최신 소스를 읽고 시작하면 됩니다.

## 2026-10-27: 종이모형 인터랙션

사용자 요청으로 화면 여백 다섯 곳에 흰색 hyparhedron 종이모형을 추가했습니다. 기존 눈과 왼쪽 작업 목록은 유지합니다. `paper-models.js`는 정다면체 5종의 곡면 패치 좌표이며 `paper.js`는 투명 Canvas에 종이 주름과 흰색 음영을 그립니다. 별도 이미지/CDN 의존성은 없습니다.

각 모형은 클릭·Enter·Space로 펼침/접힘을 토글하고 Escape로 접습니다. 움직임 줄이기 설정에서는 즉시 전환합니다. 상시 애니메이션 없이 조작할 때만 다시 그립니다. 펼침은 패치가 방사형으로 퍼지는 조형 애니메이션이며, 접착된 실제 종이의 등거리 접힘이나 제작용 전개도 시뮬레이션이 아닙니다. 웹용 모델은 앞서 만든 두께 메시를 그대로 탑재하지 않고 경량 곡면으로 표현합니다.

새 파일 변경 시 `node --check paper.js`, `node --check paper-models.js`도 실행합니다. GitHub Pages 하위 경로와 Vercel 모두 상대 경로로 로드합니다.

## 2026-10-28: 눈 구성요소 분해

SCLERA / IRIS / PUPIL 지시선과 텍스트를 접근 가능한 토글 버튼으로 변경했습니다. 공막은 위쪽 외피 타일 일부가 떠오르고, 홍채는 교대하는 부채꼴 조각이 방사형과 전방으로 분리되며, 동공은 어두운 디스크가 옆·앞으로 분리됩니다. 세 상태는 독립적으로 조합할 수 있습니다. 재클릭으로 복귀하고 ESC 또는 정면 초기화 버튼으로 모두 조립합니다.

분리량은 물체 좌표에 적용하고 투영·깊이 정렬·타일 클릭 판정을 공유하므로 분리 후에도 회전과 기존 이미지 탐색을 유지합니다. 동공의 내부 공간 진입도 이동한 디스크 위치를 사용합니다. 분리 시 정면으로 돌아오고 자동 회전은 분리 상태 동안 쉽니다. 움직임 줄이기 설정은 분리량을 즉시 전환합니다. 실제 해부학적 분해가 아니라 기존 조형을 활용한 인터랙션입니다.

## 2026-10-29: 실제 작업명 반영 시작

사용자가 확인한 실제 작업으로 왼쪽 연도별 목록을 교체했습니다. 2025: gravitational lensing, neutron star collision monument / 2024: the arc of motion. 임시 작업명 목록은 제거했고, 세 항목은 `data-image` 0–2와 `app.js`의 `names` 앞 3개로 연결됩니다. 나머지 `names` 3–11과 모든 이미지는 아직 더미입니다.

작업 사진의 원본은 Figma 파일 `스튜디오 포트폴리오 (Copy)`(The Arc of Motion / Gravitational Lens Simulator / The Phew)에 있습니다. 포트폴리오상 공식 제목은 Gravitational Lens Simulator이며 사이트 표기 통일 여부와 The Phew의 연도·추가 여부는 사용자 확인 대기입니다.

## 2026-10-29: 동공 속 천구에 첫 천체사진 배치

사용자 촬영 사진(2023-05-31)을 `images/astro/ngc6888.webp`로 배경을 투명하게 잘라 추가했습니다. 사진의 대상은 NGC 6888 초승달 성운(백조자리)이며, 사용자가 '게성운'이라고 불렀으나 형태상 초승달 성운으로 판단해 실제 좌표 RA 20h12m07s, DEC +38°21′에 배치했습니다(게성운 M1이 맞다면 `void.js`의 `photo.ra/dec`를 RA 5h34m32s, DEC +22°01′로 바꿉니다).

`void.js`의 `photo` 객체가 위치·표시 크기(`world`, 실제 18′보다 크게 확대)·이미지를 담고, 천구 좌표 표시와 같은 규칙(lon = RA, lat = −DEC)으로 그립니다. 사진 클릭 또는 하단 `NGC 6888` 버튼으로 촬영 정보 카드(`#void-info`)가 열리며 ESC는 카드를 먼저 닫습니다. 장비·노출 정보는 아직 받지 않았습니다. 사진이 늘어나면 `photo`를 배열로 바꿉니다.
